# Ruggedized VTOL UAV Capstone Project

## Introduction

This repository contains the code developed for our capstone project, which focuses on ruggedizing a Vertical Take-Off and Landing (VTOL) Unmanned Aerial Vehicle (UAV) for operation in harsh environmental conditions.

The goal of the project is to improve the UAV's ability to operate reliably in challenging environments by developing and testing hardware and software modifications.

## About This Repository

This repository will be used to store and organize the software developed throughout the project, including code related to UAV control, sensors, testing, data collection/displaying, and any supporting tools or scripts.

More documentation will be added as the project develops.
